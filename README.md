# Personal Portfolio

Peguei um template de portfólio que estava abandonado no GitHub. Pretendo atualizá-lo aos poucos, adicionando melhorias e opções de personalização para quem quiser utilizá-lo.

**Portfolio URL:** [Acesse o site](https://bielicecream.github.io/portfolio/) 

## Como publicar com GitHub Pages

1. Faça um **fork** deste repositório ou copie os arquivos para um repositório seu.
2. Se você não for usar um domínio personalizado, pule essa etapa, crie um arquivo chamado CNAME.txt com o URl do seu site.
3. No seu repositório do GitHub, acesse **Settings**.
4. No menu lateral, entre em **Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Em **Branch**, selecione `main` e a pasta `/ (root)`.
7. Clique em **Save** e aguarde a publicação.
8. O GitHub Pages exibirá o endereço do seu site na seção **Pages**.

> Se estiver usando um domínio personalizado, mantenha o arquivo `CNAME` e configure o domínio nas opções do GitHub Pages.
